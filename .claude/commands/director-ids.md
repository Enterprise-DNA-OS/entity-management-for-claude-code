description: List every director of an Australian company and whether a director ID is on file.

Read CLAUDE.md first.

```bash
npm run entities -- director-ids
```

Lead with how many are missing. A missing ID is the director's to apply for; draft them a note if asked.

Every command takes --json. Dates are YYYY-MM-DD. A name that matches more than one record lists the candidates and stops: ask which one. Never send, publish or delete from this recipe.
