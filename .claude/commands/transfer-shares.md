---
description: Transfer shares between holders and show the notice deadline where one applies.
---

Read CLAUDE.md first.

```bash
npm run entities -- transfer-shares --entity="Matai Investments" --from="Olivia Hart" --to="Noah Hart" --quantity=25 --date=2026-09-25 --actor="<operator>"
```

Read it back and wait for a yes. For a New Zealand company the transfer goes on the next annual return; for an Australian proprietary company ASIC hears within 28 days.

Every command takes --json. Dates are YYYY-MM-DD. A name that matches more than one record lists the candidates and stops: ask which one. Never send, publish or delete from this recipe.
