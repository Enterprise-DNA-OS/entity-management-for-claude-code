description: Show the share register of one entity: each holder, class, shares and percentage.

Read CLAUDE.md first.

```bash
npm run entities -- register "Matai Investments"
```

Show the register as a table. Percentages are of the class. Say the total shares on issue.

Every command takes --json. Dates are YYYY-MM-DD. A name that matches more than one record lists the candidates and stops: ask which one. Never send, publish or delete from this recipe.
